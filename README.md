# LUMA Desktop

A browser-based desktop environment built as a single HTML project. Formerly known as **CSOS**.

## Features

- macOS-inspired desktop, menu bar, Dock, windows, and lock screen
- Crisp HTML/CSS Glass Workspace home screen with glass panels, quick launch, RAM display, and responsive layout
- Animated Apple-style loading screen + optional Cooler Loading app
- Wallpaper Engine with custom wallpapers, Apple-inspired presets, animated wallpapers, and a Glass Workspace layout preset
- Browser with tabs, bookmarks, history, and the embedded LUMA Browser
- Pocket Music player with local MP3 library, playlists, favorites, and metadata
- Store for installing LUMA apps and games
- Home Screen app layout, MOD1 auto-align, and Dock management
- Notifications, widgets, settings, sound effects, and cursor themes
- Files, Calculator, Notes, Paint, Terminal, Clock, Discord, Assistant, and other built-in apps
- Custom HTML apps/games and Home Screen shortcuts
- Resizable, draggable windows with bubbly animated UI
- Local browser storage using LocalStorage and IndexedDB
- RAM/memory indicator in the top taskbar when supported by the browser

## Controls

- **Ctrl + Backspace** — remove the hovered Home Screen/Dock item from view while keeping the app available in Applications
- **Ctrl/⌘ + W** — close the active browser tab
- **Enter** — submit a browser address/search or calculate
- **Space** — play/pause Music
- **Arrow keys** — navigate Music menus / change tracks

## Version

**LUMA Desktop 3.33**

The project was renamed from **CSOS** to **LUMA Desktop** in version 3.32. Version 3.33 added the HTML/CSS Glass Workspace home screen and matching Wallpaper Engine layout.

Runs entirely in the browser. No server is required for the core desktop.

## Music Player

The LUMA Music Player is based on the MiniMP3 Player HTML project:
https://github.com/ZHelloPrint/MiniMP3-Player-html/settings/pages

## Browser

The built-in browser uses the LUMA Browser endpoint:
https://tinyurl.com/CSOSBrowser

## Notes

LUMA Desktop is a browser simulation. It does not control or shut down the real computer.
